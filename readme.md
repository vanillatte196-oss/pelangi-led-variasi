# ⚡ Pelangi LED Variasi

Landing page interaktif, simulator warna lampu kustom, dan katalog produk modern untuk **Pelangi LED Variasi**, spesialis modifikasi lampu motor & mobil (terinspirasi dari akun Instagram [@pelangi_led_variasi](https://www.instagram.com/pelangi_led_variasi) dan TikTok [@tsani_03](https://www.tiktok.com/@tsani_03)).

---

## 🚀 Fitur Utama

1. **🏠 Beranda Interaktif**:
   - Tampilan profil bengkel modern dengan tema _Dark Neon Dynamic_.
   - Navigasi multi-tab yang bersih dan cepat (Single Page Application).

2. **💡 Simulator Warna LED (Night Mode)**:
   - Pengunjung dapat menguji kombinasi warna lampu secara _real-time_ (BiLED Projie, Alis DRL, & Underglow).
   - Tombol pemesanan cepat langsung terhubung ke WhatsApp dengan membawa spesifikasi warna racikan.

3. **📦 Katalog Produk & Filter**:
   - Daftar produk lampu lengkap berdasarkan kategori (_BiLED Projie, DRL Alis, Underglow, Modul & Strobo_).
   - Desain kartu produk minimalis tanpa gambar berat, dilengkapi badge neon indikator warna.
   - Tombol order otomatis dengan pesan format WhatsApp yang rapi.

4. **🔒 Panel Admin Terproteksi PIN**:
   - Menu kelola dan tambah produk dilindungi oleh **PIN keamanan** (Default PIN: `1234`).
   - Fitur ubah PIN mandiri dan tombol _Logout_ admin agar aman dari tangan usil pengunjung.
   - Penyimpanan data produk menggunakan `localStorage` browser (aman dan otomatis tersimpan tanpa database server yang rumit).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 / CSS3** (Vanilla Structure)
- **Tailwind CSS** (via CDN untuk styling modern & responsif)
- **FontAwesome 6** (untuk ikon visual profesional)
- **JavaScript (ES6)** (Router multi-tab, state management, & localStorage)

---

## 📂 Struktur File

Proyek ini dibuat dengan konsep **Single-File Application** agar sangat mudah di-deploy ke GitHub Pages tanpa konfigurasi yang rumit:

```text
📦 pelangi-led-variasi
 ┗ 📜 index.html   # Seluruh kode website (HTML, Tailwind, JS, & CSS)
 ┗ 📜 README.md    # Dokumentasi proyek
```
